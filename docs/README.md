# Portfolio Documentation

This directory contains comprehensive documentation for the portfolio codebase, organized using the [Diátaxis documentation framework](https://diataxis.fr/).

## Documentation Types

The Diátaxis framework organizes documentation into four types based on user needs:

### 📚 Tutorial
**Learning-oriented**: For users who are new to the codebase and want to learn how it works.

- **[Getting Started Tutorial](./TUTORIAL.md)** - Step-by-step guide to understanding and working with the codebase

### 🔧 How-to Guides
**Goal-oriented**: For users who know what they want to accomplish and need step-by-step instructions.

- **[How to Add or Update Items](./HOW-TO-ADD-ITEMS.md)** - Instructions for adding/updating projects, training materials, AI experiments, and play lab items
- **[How to Add or Update Easter Eggs](./HOW-TO-ADD-EASTER-EGGS.md)** - Guide for adding interactive easter eggs or modifying existing ones

### 📖 Reference
**Information-oriented**: For users who need to look up technical details, APIs, and data structures.

- **[Reference](./REFERENCE.md)** - Complete technical reference with data models, component APIs, utility functions, and configuration details

### 💡 Explanation
**Understanding-oriented**: For users who want to understand the "why" behind design decisions and concepts.

- **[Easter Eggs Explanation](./EASTER-EGGS-EXPLANATION.md)** - Understanding the philosophy, design decisions, and implementation patterns behind easter eggs

## Documentation Framework

This documentation follows the Diátaxis framework, which organizes content based on user needs:

```
                Learning
                   ↑
                   |
    Tutorials  |  How-to Guides
    -----------+----------
    Explanation|  Reference
                   |
                   ↓
              Looking up
```

- **Tutorials** (Learning + Doing): Learn by following along
- **How-to Guides** (Looking up + Doing): Accomplish a specific task
- **Reference** (Looking up + Understanding): Look up technical facts
- **Explanation** (Learning + Understanding): Understand concepts and rationale

## Contributing to Documentation

When adding or updating documentation:

1. **Identify the user need**: What is the user trying to accomplish?
2. **Choose the right type**: Use the Diátaxis framework to select the appropriate documentation type
3. **Follow existing patterns**: Maintain consistency with existing documentation
4. **Keep it focused**: Each document should serve one clear purpose
5. **Link appropriately**: Connect related documents with cross-references
